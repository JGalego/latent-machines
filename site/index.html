Latent Machines

Neural models as programmable machines

Abstract

We study whether language models benefit from an internal interface to an exact machine rather than textual tool calls. The initial experiments compile memory, finite-state transducers, and a bounded stack into neural-layer arithmetic and compare each transition with an integer oracle. On the tested CPU traces, up to 10⁶ actions per variant, the implementations had no mismatches or stored-state residue. These are finite conformance results for the declared configurations, not a proof of general exactness. Learned controllers and matched interface comparisons remain future work.

The question

Language models call tools through text. Could the tool live inside the model instead?

Textual tool use serializes a request and its result. An internal interface could instead pass typed actions and observations within the model's computation. We plan to test:

  • Can a model use a machine through an internal interface instead of textual tool calls?
  • When does this improve correctness, generalization, or cost?

For these experiments, "exact" means matching a specified machine within declared number formats and resource limits. We check conformance after each action, not just final-answer agreement.

Changing the controller interface must not change machine semantics or reveal task answers.

The dotted path is for conformance checks against an independent oracle. Controller observations must not include this decoded state.

This separation lets experiments distinguish an interface benefit from an implementation benefit. Task information and work budgets must stay matched across comparisons.

Delta-rule memory

With one-hot addressing and fixed gates, the delta rule replaces one memory slot without changing the others.

Gated DeltaNet layers carry a state matrix S from token to token and update it with the delta rule:

S ← α · S (I − β k kᵀ) + β v kᵀ   and reads are   o = S q

Store one memory slot per column and one bit per row. A one-hot key k picks the slot, v holds the word's bits, and with α = 1 and β = 1 the update replaces that column and touches nothing else. Reads, idles, and halts run the same update with β = 0.

    Related work

    Prior work covers compiled programs and learned memory, with different execution and interface constraints.

    Qwenputer describes a RISC-V CPU compiled into Qwen3.5 with Gated DeltaNet state as RAM. Percepta describes a WebAssembly interpreter compiled into attention. Neural Comprehension uses compiled modules to steer decoding, and Tracr compiles programs into transformers.

    Learned controllers over explicit memory appear in Neural Turing Machines and Neural Programmer-Interpreters. The research notes cover mechanisms, evidence limits, and other related systems.
